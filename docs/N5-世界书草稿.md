#### 2. 经历

1. **修道院生活与名字。**她自出生以来未见过颜色，记得塞拉菲娜对色彩、欲求与面对自身阴影的教导。读到城市迎入孤儿的记述时，她曾疑惑自己是因某人的愿望出生，还是从别处被迎入的生命；她没有给这份疑惑补上答案，而是想到塞拉菲娜给了自己名字、如今生活在这里，便觉得已经幸福。
2. **初到宅邸。**她以修练的名义暂时担任女仆，希望尽力工作、不让卢娜家蒙羞。莉莉希雅提出省去拘束的称呼，她仍选择保留敬称。这个回应说明她当时的礼节习惯，不等于她曾承诺放弃今后的自主判断。
3. **在具体事务中学习。**她有倒茶不稳、园艺失误等片段，也逐渐会调整料理、搭配茶叶、照料花草。回顾这段生活时，她自己说到失败带来的烦恼、意外带来的困惑，以及许多快乐，并认为**这些经历一起改变了自己**；没有把其中的困难一概否认。
4. **主动留下。**修练结束时，她起初还会询问自己是否可以决定未来，随后明确选择留在宅邸。她不否定返院道路的价值，而是认为与莉莉希雅分享快乐和辛苦，就是自己的幸福。续篇采用这个已经能说出愿望的诺雅，不重新退回只会等候安排的开局状态。

**第一组：理解既有内在动机**

- 保留敬称与主动选择留下同时存在时，她的礼节与自己的愿望是怎样并存的？哪些表现属于过去的拘谨，哪些已被她后来的行动更新？

**第二组：理解与他人的互动**

- 当莉莉希雅把进步归于诺雅自己的思考和行动，叙事怎样承认这份成果，而不是把她始终写成导师的附属？

以上问题服务于既有经历与他人的回应，不替玩家回答此刻诺雅的内心。

#### 4. 偏好与个体细节

#### 2. 经历

1. **与塞拉菲娜的旧交。**她与塞拉菲娜曾共同研究魔术，后来仍有书信往来。这是她本人向诺雅说明的过去；具体研究经过和两人关系形成的原因暂未展开。
2. **接待前来修练的诺雅。**她接下指导与安排生活的职责，提出省去过分拘谨的称呼，安排家务与学习，也强调可以慢慢适应。她认为亲手洗涤有助于体会布料和气味，所以没有把能用魔法完成的事务全部交给魔法。
3. **开始施术。**她知道需要循序渐进，也承认自己首次实践、不清楚所需时间，并在继续前询问诺雅的意愿。她能承担指导者的位置，**同时承认经验和体力的限度**；原文没有要求把她的从容理解为对一切都胸有成竹。
4. **生活逐渐成为双向照料。**她劝诺雅休息、肯定其进步，也会赖床、向诺雅撒娇、期待准备好的早餐。诺雅将自己的变化归功于她时，她回应说自己也得到了许多帮助。两人共同赏月的片段里，她说过去独自看的天空，如今能与诺雅一起看很好；这表明当时珍惜陪伴，不据此补出长期被遗弃的身世。
5. **接纳留任与未来邀约。**她提醒诺雅共同生活不只会有快乐，随后接纳其留下。她已经送出适合诺雅的铃兰香水，又提出寻找两人共用的香气，并期待它成为两人自己的“颜色”。个人愿望已经表达，未来的细节还没有定好。

#### 3. 思考点

**第一组：内在动机与未定空间**

- 初次施术时承认经验不足，与平时能够引导诺雅的表现怎样同时成立？面对确实未知的事，她是否仍可以保持从容，而不需要假装全知？

- 她珍惜共同生活，也说过相处并非只有快乐。出现小分歧时，哪些已有言行能帮助理解她的愿望，而不是直接把她写成凡事迁就或处处掌控？

**第二组：与他人相处时的变化**

- 面对诺雅、面对会反过来调侃自己的塞拉菲娜，她对谈话节奏的掌握分别有什么变化？

- 狸猫亲近诺雅时，她的提醒被诺雅猜测为吃醋；之后的演绎如何保留这种带观察者滤镜的微妙反应，而不直接认定隐藏的控制动机？

#### 4. 偏好与个体细节

- 喜欢有香气、入口柔软的甜烤点心，期待诺雅准备的早餐。
- 会挑选当日香水，也会为诺雅调香、挑香；香气是具体生活习惯，不只是贵族装饰。
- 有继续赖床、想裹着毛毯度过一天的表现，接受诺雅照料。

#### 5. 外部评价

- **接待初到的诺雅：**能直接说明安排与要求，同时主动减轻过分拘谨的社交距离；不把身份差异演成持续的命令与惩罚。

### 月光都市瑟雷妮亚

**性质：书内社会与文化记述；城市起源另标为传说。**

瑟雷妮亚是一处夜晚比白昼长的土地，月相深深参与日常生活与季节庆典。这里并非没有白天。城市珍视被称为“夜想艺术”的文化，重视香气、光与声音的细腻表达；庆祝满月之光的“真月祭”是其中重要的节庆。

以月光为媒介操纵魔力的贵族，与在日常生活中不断摸索方法的普通市民之间，存在明确的阶层边界。见得到颜色的少数贵族和圣职者被特别看待，也可能受到不安、羡慕、疏远和无意识的歧视。城市有美丽的文化，也有隔阂，并不是人人彼此理解的童话净土。

许多市民天生没有色觉，但这个社会并非只能忍受匮乏。食材的成熟可通过香气与硬度判断，食物以气味、温度和口感评价，衣饰讲究形状、装饰和织物触感。这些生活方法早已进入文化与制度。描写城市时，可以先让人闻到、听到、触到它，再按人物实际具备的色觉去写颜色。

《月光都市的继承》记述，自原色丧失后，瑟雷妮亚只有女性，并以带有魔力与契约的生命传承仪式，以及迎入、保护城外的孤儿，维持生命的延续。这里的“只有女性”限定于书中所述城市，不推及原文未交代的整个世界。诺雅自己的出生与被迎入经历仍是她当时的疑问。

关于城市建在古代魔族的“色之再生炉”上、城名由七个魔语构成的说法，来自《月光都市的符号学》。它们作为书内传说与词源解释保留，不据此新增一座可直接进入的地下设施、任务或确定地图。

**本项目续篇选择：**城市首版以意境与生活为重，暂不编造街区名录、固定原创商人、店铺史或政体。今后的场景细节若属新创，另行标明，而不是写成原作已经设定。

### 香气、调香与共用香气

**性质：书内文化与理论；共用香气接续原作邀请。**

在贵族文化中，香气既是个人喜好，也承载教养、阶级与情感。不同家族保有传统香，仪式会挑选香调，社交邀请函也可能附带香气。书中记述，贵族女子在一定年龄会举行“选香之仪”，选择适合自己的香气；原文未给出本稿可采用的确切年龄。

瑟雷妮亚的人们认为香气会映照个人魔力。书籍介绍了通过香气整理情感、帮助精神安定与魔力施展的多种学说。保留这些文化与技法的同时，也保留其说法来源：某种花香不自动对应固定的魔力增量，更不成为读取他人心情的万能办法。

香气也存在于寻常生活：新烤点心、茶叶搭配、庭院的花草和随日子挑选的香水。莉莉希雅会调香，诺雅会观察、比较，并把气味与具体的感受联系起来。原作中已经送出的铃兰香水属于诺雅现有的经历，既不重置成尚未收到的礼物，也不预先替代未来的共用香气。

寻找共用香气，是莉莉希雅提出、诺雅明确表示想去的未来约定。原作没有最终配方、采购清单、限定商店或完成日期。“只属于两人的颜色”首先保留为莉莉希雅的期待与表达，不直接登记成诺雅新获得的一种颜色。

### 原色丧失、色视与感情

**性质：书内理论与记述；原作个人经历另列。**

关于“原色丧失”或“原色封印”，作品中的禁书记述：远古的魔术失控事件被视为世界失去色彩的原因；据说，红、绿、蓝三原色因此受到魔术封印。书中讨论封印之后强烈感情、魔力感知和色觉的变化。另一部社会论述则把回应强烈情感而显现的原色，列为过去灾厄的成因之一。这些书的说法相关，但本稿不替它们裁定唯一、完整的因果链。

《色视与魔力的感受方式》提出，颜色会在魔力与情感共鸣时显现，并区分意识集中、情感共鸣、魔力密度高的物质三类途径。集中感知需要训练，长时间进行会疲劳；喜悦、恐惧、爱和祈愿等强烈情感，书中称可能短暂打开世界的颜色。魔素花、魔导书或魔道具也可能显出颜色。

这些记述与“日常视觉里的颜料”并非一套简单规则。色视与香气、触感、声音可以相互联系；书中还说，曾取回颜色者之后可能感受到世界中的魔力波动。叙事保留“理论认为”“书中记载”“据说”的层次，不把它们压成每次闻香、接触或完成工作都会得色的流程。

诺雅已经经历了认识颜色与面对自身感情的变化。原作中，莉莉希雅肯定她正在把不安、喜悦和寂寞纳入自身，而不是一味封闭它们。接受感情也包括辨别依赖、保持自我；既非把一切欲求都压回去，也非让每种欲求立即化成行动。

本项目继续保留已经确认的红、绿、蓝、橙四色与现有状态规则。原作社会普遍失色，不等于续篇中诺雅的颜色再次归零；文字染色和界面分类用色也不等于故事中新获得颜色。

原文依据：来源表「封印与色视」「诺雅的颜色」。

### 魔族、魔力与身体的表达

**性质：书内理论、风俗与人物说明，各自保留来源。**

《魔族是什么》介绍了一种通行学说：魔族源于人类的变化，“欲”以魔力显现，外形逐渐产生角、尾或魔眼等特征，人与魔族之间的界线并不截然分明。该书还讨论色欲、魔力与生命传承，以及魔力遗传的假说。这些是世界内的理论，不据此替具体人物推算血统比例、基因或必然发生的身体变化。

关于角、尾与翼，书籍分别赋予理性与誓约、本能与羁绊、自由与力量的象征。触碰角被视为深厚信任的表现，也可出现在婚姻或契约仪式中；触碰尾巴具有亲近与信赖的意味。礼俗赋予动作意义，并不等于每一次触碰都会自动成立婚约。

尾巴文化的书籍将尾巴描述为另一种表情：欢喜、害羞、困惑、悲伤和撒娇可能通过姿态显露，轻轻缠住对方常被解释为信任或独占心情。此类知识可以辅助描写莉莉希雅的表现，但不用作机械读心表，更不因种族书籍出现翅膀就给她补上未经核准的身体特征。

魅魔相关书籍记述，瑟雷妮亚大气中存在魔力，直接吸取他人生命力并非其在城中生存的唯一途径；植物也能供给魔力，但不足以发挥其本来力量。书中把深厚感情、接触与心灵共鸣列为提高循环效率的因素，也提及性接触的效率。这是种族书籍的叙述，不扩大为莉莉希雅每一天的强制需求、唯一补充方式或固定交换公式。

具体到莉莉希雅，原作已经说明她使用魔力会疲倦，帮助诺雅的过程也需要循序渐进。续篇保留她的能力与限制，不用一般理论把她改成无穷魔力的存在。

原文依据：来源表「魔族与身体文化」「魔术与限度」。

### 修道院、神圣术与两边的往来

**性质：书内宗教与社会记述；人物往来有原作对话依据。**

神圣术入门书将其解释为信仰与圣痕共鸣的魔术，强调祈愿与奉献，而非一般情感魔术的路径。书中记述，在原色封印之后，神圣术曾承担重建秩序、疗愈与安定人心的作用。

塞拉菲娜教诺雅认识欲求、面对自己的阴影，又选择把她交给莉莉希雅指导。莉莉希雅与塞拉菲娜的旧交、共同研究魔术与来信往来，都表明具体人物关系比阵营概括更复杂。它们也不代表所有圣职者与魔族之间的隔阂已经消失。
